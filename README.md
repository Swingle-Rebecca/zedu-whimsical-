
Zedu Hello — Simple Whimsical Welcome
An independent HNG15 Task 2 design concept, not an official Zedu integration.
Idea
A calm, welcoming landing screen featuring one friendly illustrated character and a tiny interactive three-step onboarding flow.
Features
Responsive, accessible single-page HTML/CSS/JavaScript
One playful character, soft lilac tones, no complex animation
Functional “Give me a first step”, “Next little step”, and “Start over” buttons
No external packages, fonts, build tools, APIs or hosting dependencies
Run
Open `index.html` in your browser.
Deploy
Create a GitHub repository; upload `index.html` and `README.md` at the repository root. Import into Vercel with framework preset Other; deploy.
Note
This is a concept/prototype only. Confirm with the assessor whether a standalone deployed design qualifies for the task.
